# Python tooling for Core ML / Neural Engine work, pinned.
#
# Interpreter: CPython 3.14 — the project's Python standard, and what the farm runs
# (all four nodes report 3.14.7). The gates in tools/ stay standard-library-only, so
# they need none of this; only conversion work does.
#
#   uv venv --python 3.14 .venv
#   uv pip install --python .venv/bin/python -r tools/requirements-coreml.txt
#
# coremltools is pinned to an exact version *including* its pre-release suffix, and
# deliberately: CPython 3.14 has no stable coremltools wheel. 9.0 covers CPython
# 3.10-3.13, and the only cp314 arm64 wheel published so far is 9.1.dev1
# (2026-08-03). Pinning the pre-release keeps a converted model attributable to the
# exact version that produced it, which a floating dev build would not. When a stable
# 9.1 lands, move this pin to it — the round trip below is the check that it still
# converts, loads and predicts.
#
# Verified on the reference machine, 2026-09-15, CPython 3.14.7: a MIL program
# converts, saves as an .mlpackage, loads and predicts [3.0, 4.0, 5.0, 6.0] on both
# CPU_ONLY and CPU_AND_NE.
coremltools==9.1.dev1
